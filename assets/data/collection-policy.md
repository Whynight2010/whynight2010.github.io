# 离线装备媒体采集规范

## 目标

为 `china-defense-weapons.html` 的每个装备条目补充本地离线媒体：7 张图片槽位与 1 个视频槽位。素材只从无需额外资格的公开来源获取，用于本地离线自用。

## “无需额外资格”的定义

素材必须同时满足：

1. 匿名浏览器即可访问。
2. 不需要登录、注册、实名认证、机构账号或媒体账号。
3. 不需要付费、订阅、下载券、会员或商业图库授权。
4. 不需要申请素材权限、采访资质、媒体资料库权限或合作资格。
5. 不绕过 DRM、token、防盗链、验证码、加密 HLS、付费墙或登录态。
6. 来源属于官方、央媒或军工央企公开页面。

公开可访问不等于自由再分发。所有素材版权归原权利人所有，本项目仅做本地离线资料整理和展示。

## 允许来源

### A 级优先来源

- 中国军网 / 中国军事图片中心
- 国防部官网图库、视频栏目
- 新华网军事 / 新华图片公开军事报道
- 央视军事 / 央视网军事公开视频页面
- 人民网军事公开报道

### B 级补充来源

- 中国航空工业集团
- 中国航发
- 中国船舶集团
- 中国兵器工业集团
- 中国电子科技集团
- 中国航天科技 / 航天科工
- 其他军工央企或制造商官网公开新闻、产品页、专题页

## 禁止来源

- 论坛、贴吧、自媒体、搬运号、壁纸站、网盘图包、下载站
- 需要登录、付费、会员、下载券、申请授权或媒体资质的站点
- 带 DRM、加密 HLS、防盗链或动态鉴权且需要绕过才能下载的视频
- 来源不可追溯或无法确认装备型号的图片/视频
- 明确写明仅授权媒体下载、禁止转载、禁止下载的素材文件

## 状态字段

- `verified`：已确认来源合规，可本地离线展示。
- `ready`：已下载到本地，等待最终复核。
- `web_only`：公开视频页面可匿名观看，但未找到稳定、无需鉴权、无需绕过的本地视频文件。
- `fallback` / `placeholder`：未找到符合规则素材，使用本地占位。
- `needs_review`：来源、版权或型号匹配仍需人工复核。
- `rejected`：来源不符合规则，不入库。

## 图片采集规则

1. 优先下载公开页面中直接展示的静态图片。
2. 每个装备目标 7 张，命名为 `<id>-01.webp` 到 `<id>-07.webp`。
3. 优先转 WebP，长边建议约 1600px。
4. 不去水印，不删除来源标识，不做误导性 AI 修复。
5. 缺失图片使用 `assets/shared/placeholders/image-placeholder.svg`。

## 视频采集规则

1. 优先 15-60 秒、720p、MP4/H.264。
2. 只有在匿名公开、无需鉴权、无需绕过、可稳定访问 MP4 时才下载。
3. 如果只能在公开网页播放，标记为 `web_only`，不下载。
4. 不绕过播放器 token、防盗链、DRM、验证码或加密分片。
5. 缺失视频使用 `assets/shared/placeholders/video-placeholder.svg`。

## 每个素材必须记录

- `type`: image 或 video
- `status`
- `localPath`
- `sourceName`
- `sourceUrl`
- `mediaUrl`
- `title`
- `accessedAt`
- `attribution`
- `licenseNote`
- `qualificationRequired`
- `paywall`
- `loginRequired`
- `downloadMethod`
- `riskLevel`
- `notes`

## 风险等级

- `low`：官方/央媒公开页面，匿名可访问，无明显特殊下载限制，仅本地自用。
- `medium`：公开视频页面可看但不能稳定下载；或页面带较强版权提示；标记 `web_only` 或 `needs_review`。
- `high`：需要绕过技术限制、来源不明、版权明显受限；不入库。

## 推荐采集顺序

1. 歼-20、运-20、福建舰/055、99A、东风公开阅兵装备等高素材量条目试采。
2. 按空军、海军、陆军、火箭军、防空、无人机、太空/电战、单兵分批采集。
3. 每批 10-20 个装备。
4. 每批采集后更新 `media-manifest.js`、`sources-audit.json`、对应 `source.json`。
5. 断网验证页面仍能显示本地素材和占位。
